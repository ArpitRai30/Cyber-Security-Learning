## notes:
* how to open a file with spaces in its name
* use the filename in quotes 
* otherwise use \ before the spaces to escape the space 
* the file "--spaces in this filename--" requires both methods using -- or ./ before filename and use quotes 
* **solution:** `cat ./"--spaces in this filename--"`
