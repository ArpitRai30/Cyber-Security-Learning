## tar archive
* `tar file` -
archives file
* `tar -xf file` -
unarchives file

## gzip 
* `gzip file` -
compresses a file in gzip format with .gz extension
* `gzip -d file.gz` -
decompresses the file.gz (file must have .gz extension for decompression)

## bzip2
* `bzip2 file` -
compresses a file in bzip2 format with .bz2 extension
* `bzip2 -d file` -
decompresses the file
